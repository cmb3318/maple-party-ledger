사이트 안내

서비스와 권리

메이플가계부는 메이플스토리의 보스 배정과 결정석 수입을 관리하는 비공식 팬 도구예요. 게임 데이터와 이미지의 권리는 각 권리자에게 있어요.

  • NEXON Open API 캐릭터 정보와 이미지
  • 메요일 GitHub에 공개된 메이플스토리 인게임 보스 아이콘
  • 메이플스토리체 © ㈜넥슨코리아

개인정보처리방침

캐릭터 정보, 파티·보스 설정과 메모, 격파 및 분석 기록은 이 사이트에 접속한 브라우저에 저장돼요. 사이트 자체의 회원가입, 광고 추적 및 서버 동기화 기능은 없어요. 브라우저에서 사이트 데이터를 지우면 저장 기록도 지워져요.

캐릭터 조회를 요청하면 입력한 닉네임을 넥슨 API에 전달하고, 조회된 공개 정보는 Cloudflare에서 최대 5분간 캐시해요. 조회 한도를 적용하는 데 접속 IP를 사용해요. 스케줄러 실험실에 입력한 개인 API 키는 브라우저가 넥슨으로 직접 보내며 메이플가계부에 저장하지 않아요.

사이트 접속에는 Cloudflare, 캐릭터 이미지와 보스 아이콘 표시에는 넥슨과 GitHub에 대한 요청이 발생할 수 있어요. 설정 파일은 브라우저에서만 읽고 만들어요.

초기화와 문의

한국 시간 목요일 00:00에 주간 격파, 매월 1일 00:00에 월간 격파가 초기화돼요. 결정석 수입은 격파 체크와 인원수에 따라 계산해요.

오류나 권리 관련 문의는 메이플가계부 GitHub 저장소를 이용해 주세요.
